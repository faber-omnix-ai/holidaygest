# Matrice dei requisiti

Aggiornata al 14/10/2026 (versione 0.2.0). Stati: **assente** · **parziale** · **implementata** (codice presente, provata
manualmente o indirettamente) · **verificata con test** (test automatico nominato). «Collaudo pacchetto» = eseguito sul
pacchetto Windows con `build/collaudo_pacchetto.ps1`. Nessuna voce è «accettata dai portali»: la validazione è solo locale.
